# No Ecstasy, No Life — JP→EN translation quality kit

Modeled on the Belphegor pipeline (`Games/Belphegor/tooling/tl/`): every translation
request is grounded in a hand-built **game prompt** (translation bible) and a
**glossary** (characters + locked terminology) so names, voices, and gameplay terms
stay consistent across the whole game, whichever LLM does the pass.

## The store

| file | what |
|---|---|
| `tl/game_prompt.md` | Premise, mental-state/ending system, tone rules, cast voice cues, mechanical/markup rules. Prepend to **every** translation request. |
| `tl/glossary.json` | 8 name-box characters (gender/role/register/aliases) + ~100 locked terms + do-not-translate list. The single source of truth — **edit by hand** to lock a spelling. |
| `work/translation_master.json` | The translatable store: 428 dialogue lines in 22 scenes (play order, per-line speakers), charms per-asset, UI per-widget, typewriter cards, misc. Every entry carries `csv_id` → `work/translations.csv`. |
| `work/dialogue_readable.txt` | Human-readable full script (generated by `build_translation_master.py`). |

## Translating (LLM pass)

Work scene-by-scene for dialogue — each `dialogue_scenes[i]` is one coherent scene
in play order; send the whole scene in one request with the game prompt + glossary
so the model sees full context. Charms/UI/typewriter can be batched by asset.

Rules baked into the prompt (keep them if you write your own):
- Fill only `translation` fields; never touch `csv_id`/`row`/`source`.
- Preserve `<Green></>`-style markup, `<img id=.../>`, `{Placeholders}` exactly.
- （） = inner monologue, keep parentheses. ♥/♪ stay. `???` name-box stays.
- The four `GoodEnd_*` scenes are deliberate parallels of one scene — translate
  them as recognizable variants of the same lines.
- **Be concise**: injection is fixed-byte-span (ASCII must fit ~2× the JP char
  count). Overlong lines get skipped by the injector, not truncated — check
  `work/utf16le_ansi_overflow.csv` style warnings in the rebuild log.
- Leave dev/debug warnings and mojibake garbage untranslated (see
  `glossary.json#do_not_translate`).

## Applying translations

1. Copy `translation` values from `translation_master.json` into
   `work/translations.csv` by `csv_id` (speaker translations from the `speakers`
   section fan out to all of that speaker's `csv_ids`).
2. Rebuild + pack:
   ```powershell
   powershell -File tooling\scripts\05_apply_text_and_rebuild.ps1
   powershell -File tooling\scripts\06_pack_patch.ps1 -Install
   ```
3. Watch the rebuild log for `skipped fixed-span raw string` warnings → shorten
   those lines (or extend the injector with a DataTable-safe resize mode).

## Regenerating the store

After re-extracting assets (scripts 02–04):
```powershell
python tooling\scripts\build_translation_master.py
```
Safe to re-run; it rebuilds `translation_master.json` from the current JSON
exports + `translations.csv`. The glossary and game prompt are never overwritten.
