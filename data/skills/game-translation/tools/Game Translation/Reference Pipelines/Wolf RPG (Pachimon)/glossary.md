# Game Glossary

Use this glossary for consistent names, roles, terms, tone, and UI wording.

## Main Characters And Recurring Speakers

アラレ (Arare) - Female protagonist / heroine. Energetic, earnest, impulsive, sometimes embarrassed but usually forward-moving. Use a lively first-person voice when she speaks. Keep as Arare.

Arare (Arare) - Romanized form of アラレ. Keep consistent.

シロップ (Syrup) - Female Deviser / important rival or partner figure. Competitive, upbeat, sharp, often confident and encouraging. Keep as Syrup.

Syrup (Syrup) - Romanized form of シロップ.

ボククン (Bokkun) - Main monster / partner monster name. Cute creature-like name. Keep as Bokkun.

Bokkun (Bokkun) - Romanized form of ボククン.

ママ (Mom / Mama) - Arare's mother and a powerful Core Master figure. Warm, maternal, teasing, confident. Use "Mom" when Arare addresses her naturally; use "Mama" in title-like terms such as Mama Star if the source uses ママ as a stylized name.

ハカセ (Professor) - Female professor/researcher and tutorial mentor. Bright, playful, teasing, knowledgeable. Translate as Professor when used as a title/speaker.

博士 (Professor) - Same role as ハカセ unless context clearly means a generic doctor/scientist.

ライバル (Rival) - Female rival tag when no personal name is exposed. Confident, competitive, teasing. Translate visible role as Rival only if it is shown as a label.

ジムリーダー (Gym Leader) - Formal first Challenge Gym leader / administrator. Polite, dignified, ritualistic. Uses わたくし; translate with composed formal English.

ファストアドミニストレータ (Fast Administrator) - Administrator/Core Master for Fast City or the first area. Formal and dignified unless surrounding context says otherwise.

アドミニストレータ（アイドル） (Idol Administrator) - Female idol-like Administrator/Core Master. Sparkly, theatrical, polite, uses star/idol energy. Translate as Idol Administrator if no personal name is supplied.

ユニ (Yuni) - Female idol Core Master. Cheerful, performative, confident, star-themed. Keep as Yuni.

夢角ユニ (Yuni Yumekado) - Full name for Yuni. Keep as Yuni Yumekado.

琵琶シティアドミニストレータ (Biwa City Administrator) - Administrator/Core Master of Biwa City. Usually this is Berina. Uses playful watery speech and の～ endings. Translate as Biwa City Administrator if the display name is a role label.

ベリナ (Berina) - Female water-themed Core Master / Biwa City Administrator. Playful, floaty, childish-cute, watery, often says なの～. Keep as Berina; reflect her airy cute rhythm without baby talk.

ヴェラ (Vera) - Female Core Master of the Germ type. Stern, dominant, direct, uses a stronger declarative register. Keep as Vera.

カリン (Karin) - Female Deviser/rival name in league context. Keep as Karin.

ピエロ・エロ (Pierrot Ero) - Adult game-show clown/host. Loud, theatrical, sleazy, pun-heavy, showman energy. Keep name as Pierrot Ero.

Game host / 実況 (Commentator) - Sports-announcer voice. Energetic, loud, dramatic.

観客 (Audience) - Crowd lines. Loud, excited, casual.

## Honorifics And Address

さん (-san) - Preserve as -san in visible dialogue when it marks relationship or politeness. Omit only in compact UI/system text.

ちゃん (-chan) - Preserve as -chan in visible dialogue, fan chants, nicknames, and affectionate address. Use tone rather than the suffix only when the phrase must be naturalized.

様 (-sama) - Preserve as -sama for direct address or stylized reverence. Use Lord/Lady/Master only when context clearly demands an English title.

くん (-kun) - Preserve as -kun in visible dialogue when it marks familiarity.

先輩 (senpai) - Use senpai when used as address.

先生 (sensei) - Use sensei for address, Professor/teacher/doctor for role labels depending context.

お嬢様 (young lady / milady) - In maid speech, use "milady" or "young lady" depending tone.

キミ / あなた / あんた - Translate by relationship: you, kid, you there, etc. Keep tone.

## Style Notes

- Keep character names romanized consistently.
- Do not invent official spellings when the glossary gives one.
- For unknown proper nouns, romanize cleanly rather than translating literally.
- Preserve adult intensity when present, but do not make neutral lines more explicit.
- Preserve comedy puns when possible, but prioritize meaning and clarity.
- For robot lines, slight stiffness is okay: "Please proceed", "Confirmed", "You may board".
- For UI, prefer short labels over full sentences.
- For battle narration, use compact game-like phrasing.
- For debug/sample-map text, translate accurately even if it feels out of-world.
