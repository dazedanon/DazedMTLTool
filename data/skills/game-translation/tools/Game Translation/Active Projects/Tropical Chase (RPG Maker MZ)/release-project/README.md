# Tropical Chase! - English Patch

English text, menus and 44 translated images. Translation by **len**.
Requires your own Windows copy of the game.

## Install

1. Close the game and back up your original game folder.
2. Copy `data`, `img`, `js`, `index.html` and `package.json` into the folder containing `tropical-chase.exe`. Merge folders and replace files when asked.
3. Launch `tropical-chase.exe` normally.

Existing saves work. An event already running in an older save may stay in Japanese until it ends.

To uninstall, restore the files from your backup and delete `js/plugins/TropicalChaseEnglish.js`.
