# Validation plan

## Offline preparation gates

Verify the immutable selected source snapshot and the whole text/runtime file manifest before using the catalog.
Bind source metadata, reviewed injection sites, and tooling to the catalog fingerprint.
Re-extraction must retain targets and reject missing units or changed sites.
An empty-target staged build must match every snapshotted file byte for byte.
Synthetic targets must reach every selected site, retain all JSON structure and protected fields, preserve original dictionary entries, and pass JavaScript reparsing and decoded-value readback.
Exercise the real validator with missing, duplicated, malformed, and reordered placeholders, stale metadata, residual source characters, and invalid target types.
Run the shipped localization functions in isolation with synthetic dictionary entries to verify hash tags, English spaces, multiple tags, and color-tag handling.

## Coverage limits

Preparation readiness applies only to the reviewed nonsexual general UI catalog.
The remaining narrative, content-specific UI, nested action scripts, other plugin literals, bound save-preview fields, and unreviewed database surfaces are not certified by that catalog.
Exclusion records contain paths and reasons rather than scene text.
Images are outside the requested scope.
No English locale is enabled and no build is installed.

## Later UI and layout checks

Use native font rendering to measure each permitted widget separately, including headings, buttons, save-slot suffixes, and variable-substituted labels.
Static font advances are a preparation aid only; record missing glyphs and do not call them exact rendered ink bounds.
Use the actual painted plate and adjacent controls as bounds when those are tighter than the nominal widget.
Settings use picture-backed controls as well as live text, so a complete literal catalog would still not prove complete visual coverage.
The dialogue plugin's configured 1720-pixel width, 42-pixel font, three rows, and automatic wrapping are this game's settings, not a native fit certificate.
Do not import Tropical Chase's 780-pixel or 26-pixel measurements.

## Later runtime checks

Launch an isolated test copy with Fargus when available.
Do not use the player's save directory.
Verify the real English locale-selection path and cached configuration before claiming an English build works.
The configured English common-event replacements still contain Chinese and must not be activated as a completed translation.
Check that script parameter names resolve after the engine's plugin-path handling and that MUUI's dynamically loaded modules receive their patches.
For permitted UI changes, test title, settings, save/load screens, normal Save/Load handlers, and repeated load/save behavior.
Check advancing frames and the engine error panel, not only process or IPC responsiveness.

## Saves and release

Command index preservation, cached display text, and read-history identity require separate checks.
NovelGameUI keeps read/skip state; do not assume event-list structure proves read-history compatibility.
Nameplate display strings can also be matched by `BY_MessageWindow` special-name configurations and can carry `BY_Liv` portrait suffixes.
Any future permitted name changes must preserve those consumers together.
No save migration is implemented during preparation.
Do not package or install this project's staged subsets as a full game patch.
