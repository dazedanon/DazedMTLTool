# Cross-cutting wording conventions

- Use Save and Load for the paired screens and keep their confirmation questions parallel.
- Use New Game for the title command; use Restart only if the actual action restarts an existing session.
- Use Skip Read Text for a compact toggle, and Only Skip Read Text where a full option label is needed.
- Use Autosave consistently as one word and Empty for an unused save slot.
- Use sentence case for confirmation questions and title case for short menu labels.
- Keep interface wording neutral and direct; do not copy the game's dramatic narrative register into settings or save prompts.
