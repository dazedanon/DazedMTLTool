# Reconcile review decisions before changing translation scope

Use this when a user disputes an exclusion, a later review contradicts an earlier one, or a resumed task is about to suppress previously accepted work.
Inspect the current source, prior decision record, user correction and any recorded retraction together.
An exclusion file is a past judgment, not independent evidence that its judgment is correct.
Do not reinstate a retracted decision from the same evidence without explaining what new fact changes the conclusion.

## Evidence and scope

Distinguish source facts, user-provided context and the assistant's interpretation.
Record exact source locations and the relevant wording, plus the decision it supports and any uncertainty.
Keep confirmed age/adulthood lore separate from art style, short stature, youthful wording, sibling roles and ambiguous labels such as “girl”.
Cartoony, chibi, super-deformed and low-resolution sprite designs are not age categories.
Features shared across the art style, including large heads, simplified faces and small bodies, do not by themselves establish a minor identity.
Interpret age-related wording in its full context, including whether an older speaker is speaking comparatively; do not invent a numerical age from an ambiguous label alone.
Read the complete local context and established character lore before applying an age-related exclusion.
Do not repeatedly reopen the same question for unchanged characters merely because another stylized image or the same ambiguous wording appears.
A reviewed correction remains current unless specific contrary evidence warrants a documented revision.
A stated adult age does not override clear contrary child depiction; an ambiguous appearance comparison also must not silently override established adult context.
Do not invent ages, age up characters, change characterization or rewrite an excluded scene into a substitute.
Evaluate genuinely contrary evidence at the specific scene/participant level instead of extending a keyword judgment to an entire species or cast.

For mixed content, inspect exact occurrences and independent UI uses.
A shared short label can have unrelated uses elsewhere; global Japanese-text suppression can discard valid translations.
Explicit engine identifiers, non-player-facing development content, user-approved omissions, unresolved extraction and content restrictions are different dispositions.
A parser or error message is not automatically an internal identifier: trace its consumer and report whether the player can see it.
Translate player-visible diagnostics when they are in the requested scope, preserving formatting arguments and technical keys.

## Preserve corrections across resume and reinjection

Keep a short current decision record with source bindings, rationale, scope, date and links to the review it supersedes.
Archive the previous decision rather than deleting its history.
Check the current record on resume, before expanding exclusions and before injection; a stale exclusion list must not silently override a later reviewed correction.
When a decision changes, reconcile batch selection, exact occurrence filters, injection, QA allowlists, progress denominators and delivery notes together.
Keep historical accepted translations intact so a mistaken exclusion can be reversed without retranslating or reconstructing source.
Restoring eligibility does not by itself validate an old translation: check its source, context, placeholders, speaker association and current layout before restoring it to the game.
Recheck newly encountered contrary evidence independently; prior acceptance is not an unconditional permission rule.

## Make remaining Japanese visible to the user

Show a compact disposition summary at milestones and delivery: translated/reviewed units, remaining untranslated player-facing occurrences, explicit exclusions, unresolved items and accepted artwork exceptions.
State the counting unit; logical dialogue blocks and native displayed lines are not interchangeable.
Put material omission counts and reasons in the main progress/handoff summary, not only in a long local ledger.
If a denominator covers only eligible text, say so alongside the number and show the excluded total separately.
Do not report a fully translated game because an eligible-only counter reaches 100% or an exclusion-aware audit has no unknown entries.
An audit of residual Japanese must join each finding to its evidence-backed disposition and check that the exclusion is still current.
