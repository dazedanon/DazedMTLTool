# Problems & Continuing Later

Most problems do not mean your work is lost. Read the newest message in **Activity**, then find the
matching problem below.

## Common problems

### The API key is invalid

Open **Configuration** and carefully paste the key again. Check that the provider matches the
company that gave you the key. For example, a Mistral key must use Mistral as the provider.

### Too many requests or rate limit

The AI company is asking you to slow down. Wait a little while and try again. Free services may
have smaller limits. Translate fewer files at one time if it keeps happening.

### Payment, credit, or quota error

Sign in to the AI company's website and check the account. The account may need credit, or it may
have reached its spending or free-use limit. DazedTL cannot change the company's account limits.

### Connection error

Check that websites open normally on the computer. Then try again. A temporary problem at the AI
company may also clear up after a short wait.

### One file keeps failing

Try translating that file by itself. If it still fails, open **Activity** and copy the newest error
into your Agent. Ask it to explain the error in simple language before changing anything.

### DazedTL found no game files

Choose the folder containing `Game.exe`, not a shortcut, ZIP file, or a folder above it. If the
game is still inside a ZIP file, extract it first.

### The Agent cannot see the game

In Cursor or VS Code, click **File → Open Folder** and choose the same working game folder you chose
in DazedTL. Start a new Agent chat after opening the correct folder.

## Can I stop and continue later?

Yes. Wait for the current file to finish if possible, then close DazedTL normally. Do not delete
the `files`, `translated`, or `.dazedtl` folders. Open the same game folder when you return.

Already finished translations remain in the `translated` folder. You can select the unfinished
files and continue without translating the completed files again.

If you started a Batch job, open **Batches** later to check it. A Batch job may continue at the AI
company even while DazedTL is closed.

## The game stopped working

Stop and do not keep adding changes. Return to the untouched backup you made before starting, or
copy a clean game again and repeat only the small group of files that last worked. See **Backups &
Recovery** for the safest recovery steps.
