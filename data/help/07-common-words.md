# Common Words & Buttons

Open this page when DazedTL or the Guide uses a word you do not recognize. You do not need to
memorize any of this.

## AI words

| Word | What it means |
|---|---|
| **Provider** | The company whose AI you are using, such as Mistral, Anthropic, or OpenAI |
| **API key** | A private password that lets DazedTL use that company's AI service |
| **Model** | The particular AI you chose from that company |
| **Agent** or **AI helper** | The chat helper in Cursor or VS Code that can look through the game folder and help with extra tasks |

## Game words

| Word | What it means |
|---|---|
| **Game folder** | The folder containing the game, usually including `Game.exe` |
| **Engine** | The program originally used to make the game, such as RPG Maker or WOLF RPG |
| **Map** | One room, town, field, or other area in the game |
| **Database** | The game's main list of names, items, skills, descriptions, and settings |
| **Glossary** | A saved list telling the AI how important names and words should be translated |

## Common buttons

| Button or word | What it does |
|---|---|
| **Import** | Copies game text into DazedTL's work area |
| **Translate** | Sends the selected text to your chosen AI service |
| **Export** | Puts translated RPG Maker text back into the working game |
| **Preview** or **Precheck** | Shows what DazedTL plans to change without changing the game |
| **Inject** | Puts translated WOLF RPG text back into the working game |
| **Patch** | Replaces a selected game file, often a picture, with your edited version |
| **Rewrap** | Rearranges long English lines so they fit inside text boxes |
| **Activity** | Shows what DazedTL is doing and any error messages |

## Translation choices

| Choice | When to use it |
|---|---|
| **Normal** | The easiest choice for a first test or a small translation |
| **Batch** | A slower background job for a large amount of text, if your AI company supports it |
| **Phase** | One section of translation work, such as names, game information, or maps |
| **Playtest** | Start and play the game to check the translation and make sure it still works |
