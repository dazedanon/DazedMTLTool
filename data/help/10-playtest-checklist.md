# Playtesting Checklist

Playtesting means starting the game and checking the translated parts yourself. A translation job
finishing without an error does not prove that the game looks right or still works.

## After each small export

- Start the game normally.
- Load a save near the translated area, or begin a new game if needed.
- Open the main menus and check item, skill, character, and location names.
- Play every map or scene you just translated.
- Save and load once to make sure both still work.

## Look for translation problems

- A name is spelled differently in two places.
- A sentence sounds confusing or does not match the scene.
- Text runs outside its box or covers another part of the screen.
- A line breaks in an awkward place.
- Japanese text is still visible.
- A picture, button, or menu is too crowded after editing.

For text inside pictures, inspect every edited image before patching it into the game. Smaller AI
models may miss small writing or place English badly, so difficult images need extra care.

## When you find a problem

Take a screenshot and write down where it happened. If Japanese text remains, the Windows
Snipping Tool can copy words from the screenshot. Give the screenshot, copied words, and location
to your Agent so it can help find the source.

Fix and test a small problem before making more changes. If good English is simply too wide, use
the RPG Maker **Rewrap** step.

## Before sharing the translation

- Play from the beginning to the ending, not only from old save files.
- Ask another person to try it if possible; they may make choices you did not test.
- Build or copy the final translation onto a clean game copy and test that copy.
- Check that no API keys, private notes, screenshots, or personal files were included.
- Keep your untouched game and translation work after release in case you need to fix something.
